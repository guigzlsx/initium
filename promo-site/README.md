# Initium — page promotionnelle

Landing page statique, sans dépendance, prête à être déployée sur Vercel.

## Déploiement Vercel

Depuis le dashboard Vercel :

1. Importer le repository GitHub `guigzlsx/initium`.
2. Définir `promo-site` comme **Root Directory**.
3. Laisser le framework sur **Other**.
4. Laisser les commandes Build et Output Directory vides.
5. Déployer.

Le site est composé uniquement de `index.html`, `styles.css`, `script.js` et `vercel.json`.
